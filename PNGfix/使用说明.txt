PNG 透明修复工具
================================================
修复 After Effects 导出 PNG 的「透明通道」问题


【这个工具做什么】

把 AE 导出的「预乘黑底」PNG，转换成标准「未预乘 (straight alpha)」PNG。


【它不是"去黑"工具 —— 重要】

它**不会**把画面里的黑色去掉，也不会改变任何颜色。

它修的是**透明通道的解读方式**：

  修复前                              修复后
  ─────────────────────────────────────────────
  透明区 → 多数软件里显示成黑块        透明区 → 变回透明
  半透明边缘 → 发暗、发灰              半透明边缘 → 颜色还原

画面本身的颜色（包括本来就是黑色的部分）完全不动，
Alpha 通道也一点不改，只改变 RGB 的存储方式。


【背景：为什么需要它】

After Effects 的 saveFrameToPng 导出的是「预乘黑底」PNG：
透明区的 RGB 被乘成了黑色，半透明区的颜色也被压暗。

这种图在 AE 里看着正常（因为脚本设了 PREMULTIPLIED），
但用 PS / 图片查看器打开就会出问题。

本工具把它转成标准「未预乘」PNG，转换后任何软件打开都是正确的。


【怎么用 —— 三种方式】

方式一：拖拽（手动）
1. 把 PNG 文件或文件夹，拖到「拖到这里修复.bat」这个图标上
2. 松手，等待处理（3840×2160 的大图约 1 秒）
3. 窗口显示绿色「✓ 处理完毕」，停留 3 秒后自动关闭

支持：
  · 单个 PNG 文件
  · 多个 PNG 文件一起拖（选中多个再拖）
  · 整个文件夹（自动处理里面所有 PNG，含子文件夹）

方式二：文件夹自动监控（常驻）
1. 把「自动监控.bat」复制到你的 _raster_cache 文件夹里（或任何想监控的目录）
2. 双击运行它，会开始常驻监控该文件夹
3. 之后 AE 导出、或你丢进来的任何 PNG，都会被自动修复为「标准透明」
4. 按 Ctrl+C 停止监控

方式三：与 SY_Merge 联动（全自动，推荐）
1. 把整个 PNGfix 文件夹放进 SY_Merge.jsx 所在的 ScriptUI Panels 文件夹
   —— 工具是单文件 fix_alpha.exe（已内置 Python 运行时 + numpy + Pillow），
   目标电脑无需装 Python，完全自包含。
2. SY_Merge 面板里勾选「合并后自动修复导出PNG（外部工具转标准透明）」
3. 点击「合并」后，脚本会自动调用本工具处理导出的 PNG
4. 处理后的文件在 PS / 图片查看器里也正确，AE 内显示同样正确（已改为按 straight 导入）
5. 脚本自动优先找「同级 PNGfix/fix_alpha.exe」；找不到才回退本机 Python。
   所以不复制也能用（本机），复制过去就是完全自包含版。


【输出】

直接覆盖原文件 —— 文件名不变，内容已修复。

  raster_123.png  →  raster_123.png（已修复，原图被覆盖）

原图是脚本生成的，需要的话可从 AE 重新导出一份。
如果想留底，请在拖入前自己另存一份。


【做了哪两件事】

1. 颜色还原（核心）
   公式：未预乘 = 预乘值 ÷ (alpha/255)
   把被压暗的半透明区颜色还原回来。

2. 透明区填充（附加）
   完全透明区（alpha=0）的原始颜色在预乘时已经丢失了，
   不处理的话，不支持透明通道的查看器会显示成黑块。
   这里用「从内容边缘向外扩散颜色」的方式填充，
   让那些查看器看到的是内容色的延伸，而不是黑块。

   Alpha 通道全程不改动，透明区域依然透明。


【自动跳过】

工具会先判断图片是不是预乘黑底：
  · 是 → 修复
  · 不是（已经是未预乘）→ 跳过，不重复处理
重复拖同一张图不会把颜色搞乱。


【已知限制（重要）】

预乘会造成不可逆的信息损失：
  完全透明区原本是什么颜色，文件里已经不记录了。

所以：
  · 在支持透明通道的软件里（PS、AE、浏览器）—— 完全没问题
  · 在不支持透明通道的查看器里 —— 透明区显示的是「推算出来的邻近颜色」，
    不是原始颜色。绝大多数情况看着自然，但不保证 100% 还原。

如果图片本来就没有半透明区域（只有全透明 + 全不透明），
修复效果最完美；半透明越多，边缘推算的误差空间越大。


【技术说明 —— 单文件 exe，完全自包含，拷贝即用】

本工具已打包成单个 fix_alpha.exe（内置 Python 运行时 + numpy + Pillow，约 35MB），
不依赖任何外部 Python 安装。只要把整个 PNGfix 文件夹一起拷贝，就能在任何 Windows 电脑上用。
PNGfix 文件夹里不再需要庞大的 python 子目录。

  换电脑部署（完全自包含）：
    1. 把 SY_Merge.jsx 放进新电脑 AE 的 ScriptUI Panels 文件夹
    2. 把整个 PNGfix 文件夹（含 fix_alpha.exe）也放进同一个 ScriptUI Panels 文件夹
    3. 重启 AE，从 Window 菜单打开 SY_Merge —— 无需在那台电脑装 Python
  脚本会自动优先用 PNGfix/fix_alpha.exe；没找到才回退到本机 WorkBuddy venv 的 python。

bat 文件用 %~dp0 相对定位，PNGfix 文件夹可随意移动或改名
（只要 fix_alpha.exe 在 PNGfix 里即可）。
